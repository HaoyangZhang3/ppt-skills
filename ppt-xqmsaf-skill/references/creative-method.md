# 《喜鹊谋杀案》风 PPT 的原始创作方法（视频版 + 本技能实现对照）

来源：抖音教程视频（4′24″，水印"273551374010"），内容为把一套"塔"主题 PPT 改成《喜鹊谋杀案》式暗调悬疑风。下文"视频做法"是视频里的 PowerPoint 原生操作，"本技能"是用 `build_xqmsaf.py` 的等价实现。

## 风格量化档案（视频成品实测）

| 项目 | 值 |
| --- | --- |
| 页面底色 | 近黑深酒红 #430103 ~ #450001（黑底 + 满页红矩形叠加合成） |
| 强调红 | #9E0007，暗棕红 #733F41 |
| 文字/高光 | 暖白 #E8D2CF（非纯白） |
| 灯光 | 淡黄色（PPT 标准浅黄系），光锥透明度 45% |
| 成品页亮度 | 平均 22~42/255，中心略亮于四角 |
| 氛围 | 黑场 + 暖黄光斑 + 酒红洗色 = 悬疑老电影/侦探小说封面感 |

## 一、灯光效果

### 1. 灯源（灯泡）
视频做法：插入圆形 → 填充**淡黄色** → 线条**无线条** → 复制一个 → 把其中一个**调整大小**（一大一小叠放）。
本技能：`add_lamp()` —— 大圆 62% 不透明 + 柔边、小圆 96% 不透明偏移左上，对象名 `xq-lamp-a/b` 跨页固定供 Morph 匹配。

### 2. 光锥（柔光）
视频做法：插入**"被咬了一口的饼形"**（部分饼图）→ 调成扇形 → 填充与灯源同色 → **透明度 45%** → 觉得呆板 → **柔化边缘**（把角磨平）。
本技能：`add_cone()` —— PIE 扇形，`adjustments=±spread/2`、`rotation=dir`，填充淡黄 + `a:softEdge`（半径 6%）。参数 `cone: {dir, spread, length}`。

### 3. 满页红蒙版（整页洗色）
视频做法：背景调**暗色** → 再画一个**满页面矩形** → 填充红色 → **透明度 47%**。黑底被压成深酒红，AI 图片也统一进食色调。
本技能：`xq-wash` 满页矩形，`wash_alpha: 47`（透明度%）。

### 4. 灯光照耀图片（核心）
视频做法：**复制 3 页** → 图片置于顶层 → 调灯光位置大小 → 全选图片+灯光 → **合并形状**（按效果推断为"相交"，得到只在光锥内可见的图片）→ 原来的图片置于底层 → 剪出的形状放对应位置 → 灯光照耀效果。
本技能：`make_lit_picture()` —— Pillow 在图片上按灯心/方向/张角抠**羽化扇形 alpha**，生成 RGBA PNG 覆盖在同位置（`xq-lit`）。离线、像素级对齐、不依赖 PowerPoint UI；羽化边替代"柔化边缘"。

### 5. 开灯动画
视频做法：把之前准备的圆形**压扁拉伸**（宽度对齐光锥边缘）当光晕 → 按住 Shift 选中**灯光 + 扁圆** → 加**擦除动画** → 动画窗格：**效果从顶端**、**开始与上一动画同时**、**持续时间 0.5 秒** → 再给这页 PPT 加**平滑切换**。
本技能：`xq-glow` 压扁椭圆（沿光锥方向）+ `xq-cone`（有图时含 `xq-lit`）统一加 **wipe(down) / presetID 22 / subtype 4**，0.5s，`timing` 组用 `onBegin tn=2` 条件自动播放。参数 `light_on: true`、`wipe_ms: 500`。

### 6. 聚光灯转移
视频做法：文字+灯源**组合** → 加**随机线条**动画 → 复制到第二页并替换文字灯源、删第二页动画 → 第二页给汇报人名称 → **文字透明度 74%** → 复制这页把文字透明度**改成 0%** → 调整灯光和扁圆位置大小 → 删除剪切好的图片 → 翻页时灯移过去、文字亮起来。
本技能：跨页同名对象 + `text_transparency: 74 → 0`（PowerPoint 语义：74 = 74% 透明）；`title_reveal: "bars"` 给标题加 `randombar(horizontal)`（presetID 14/subtype 10）报幕出场。

## 二、图片处理

视频做法：
1. 想把图片调成喜鹊风——擅长绘画的自己画
2. 不会画就靠 **"百度搭子"**（百度 AI 生图）：上传准备好的建筑或人物图片
3. 让它**直接生成这种风格的图片**（暗调、酒红、版画/油画质感）
4. 把处理好的图片**直接进 PPT** → 背景调**暗色** → 盖满页红蒙版统一色调

关键认知：**风格化由 AI 完成，不是 PPT 内置艺术效果**。本技能不绑定生图工具：接收任意图片，负责"进 PPT 之后"的暗场处理（cover 裁剪 + 暗底 + 红蒙版 + 光照图）。示例图可用 `make_demo_assets.py` 程序生成。

## 三、页面衔接（平滑切换 Morph）

视频做法：
- **全片切换统一"平滑"**（142.5s 字幕"加上平滑切换"）——Morph 按对象/名称补间，不是换图。
- **把灯光藏进灯源**：目录页的灯光收到灯里（本技能 = 该页 `cone.length: 0.02`）。
- **目录→内容页"丝滑衔接"配方**：复制做好的目录页 → 新页**拉大图片**、**字号调大**、加上内容、灯光藏进灯源 → **回到目录页**，把大图**粘贴到画面外** → 平滑切换播放时大图从画外滑入（本技能 = 上一页 `image_box` x≥0.9，下一页 x=0.52）。
- 内容各节衔接同理："选中要讲解的部分置于顶层，灯光大小方向调整"；结尾原话"后面部分的操作基本都是这样"。

## 本技能参数对照

| 视频操作 | 配置/对象 |
| --- | --- |
| 淡黄圆形灯源 | `lamp: [x, y, r]` → `xq-lamp-a/b` |
| 饼形扇形柔光 45% | `cone: {dir, spread, length}` + `cone_alpha: 45` |
| 满页红矩形 47% | `wash_alpha: 47` → `xq-wash` |
| 合并形状相交 | `lit: true` → Pillow 羽化扇形 `xq-lit` |
| 擦除·自顶部 0.5s 同时 | `light_on: true` + `wipe_ms: 500` |
| 随机线条 | `title_reveal: "bars"` |
| 文字透明度 74→0 | `text_transparency: 74 / 0` |
| 平滑切换 | 全页 `p159:morph byObject`（`morph_ms`） |
| 灯光藏进灯源 | `cone.length: 0.02` |
| 大图移出画外再滑入 | `image_box` 跨页改 x |

## QA 指标（视频成品与生成件对照）

- 成品页平均亮度 25~65/255；最亮点（灯心）≈ 238+。
- 页面主色应落在 #43~#57 的深酒红区间（取决于 `wash_alpha`）。
- 内容页"亮区"必须对应光锥方向；灯光不得压住标题文字；正文不得溢出。
- 动画/Morph 只在 PowerPoint 放映可见：第 1 页无进入切换，其余页 Morph；cover/section 进入后 0.5s 自动开灯。
